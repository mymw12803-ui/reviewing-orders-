# نظام فحص وتجهيز الأوردرات بالباركود - خيام ستور (Khiam Store)

نظام فحص وتجهيز ذكي وفائق السرعة لمخزن الملابس، يعمل كـ **Static Web App** مستقل (جاهز للاستضافة على GitHub Pages)، وكـ **Chrome Extension (Manifest V3)** للربط المباشر مع أوبريكس وبوسطة وشوبيفاي.

---

## ⚡ خطوات التشغيل السريع (خطوتان فقط)

### 1️⃣ الطريقة الأولى: التشغيل كرابط مباشر على GitHub Pages (أو المتصفح فوراً)
1. قم برفع ملفات المشروع إلى مستودع GitHub، ثم ادخل على:
   `Settings` -> `Pages` -> اختر فرع `main` واضغط **Save**.
2. سيمنحك GitHub رابطاً مباشراً مجانياً (مثال: `https://username.github.io/khiam-warehouse/`).
3. *(بدون استضافة):* يمكنك أيضاً فتح ملف [`index.html`](index.html) مباشرة بالنقر المزدوج عليه في أي متصفح (Chrome أو Edge) وسيعمل النظام بكامل مميزاته محلياً.

---

### 2️⃣ الطريقة الثانية: التثبيت كـ Chrome Extension (Manifest V3)
1. افتح متصفح Google Chrome واذهب إلى الرابط:
   ```
   chrome://extensions/
   ```
2. في أعلى اليمين، قم بتفعيل **وضع مطور البرامج (Developer mode)**.
3. اضغط على زر **تحميل حزمة غير مضغوطة (Load unpacked)**، ثم اختر مجلد هذا المشروع:
   `f:\0\مراجعة المنتجات`
4. ستظهر إضافة **"خيام ستور | فحص الأوردرات بالباركود"** في شريط أدوات المتصفح، وبالضغط على أيقونتها ستفتح شاشة الفحص في تبويب كامل مستقل.

---

## 🌟 أبرز مميزات النظام المدمجة:
- **معالج الكيبورد العربي التلقائي 100%:** تصحيح مسح الباركود تلقائياً حتى لو كانت لغة جهاز الكمبيوتر مضبوطة على العربية، مع حماية 600ms ضد تكرار قراءات القارئ المزدوجة.
- **التوجيه الصوتي العربي الفوري (Web Speech API):** توجيه صوتي بشري واضح ("أوردر جديد: قطعتان"، "باقي قطعة واحدة"، "تم اكتمال الأوردر، أغلق الكيس"، إلخ).
- **كاشف اختلاف المقاس الذكي (Size Mismatch Detector):** إذا مسح العامل نفس الموديل ولكن بمقاس مختلف عن المطلوب، ينبهه النظام صوتياً وفورياً: *"انتبه: الموديل صح ولكن المقاس مختلف! المطلوب مقاس [X] والممسوح مقاس [Y]"*.
- **كشف أوردرات الاستبدال (`EXC-`):** تنبيه برتقالي فوري ووامض للتأكد من استلام المرتجع أولاً.
- **طباعة كشف تسليم مندوب بوسطة (Bosta Handover Manifest):** زر لطباعة كشف تسليم رسمي جاهز للتوقيع بمندوب الشحن وإجمالي القطع والشحنات.
- **وضع استعلام عن الصنف التائه (Lost Item Finder):** مسح أي قطعة تائهة لمعرفة العميل والبوليصة المطلوبة فيها فوراً.
- **مزامنة شوبيفاي مع Dexie.js و 0ms Preloading:** سحب الصور وتخزينها في IndexedDB محلياً وظهورها في **0 مللي ثانية**.
- **قراءة بوالص PDF واستخراج الملاحظات والتعديلات:** قراءة ملفات بوالص بوسطة PDF واستخراج الملاحظات الخاصة وإظهارها كتنبيه بارز للعامل.
- **الزر العائم على أوبريكس:** يظهر تلقائياً على صفحات التحضير في `khiiam.operix.co` لنقل الدفعات للشاشة بضغطة واحدة.
