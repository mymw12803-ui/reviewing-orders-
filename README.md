# نظام فحص وتجهيز الأوردرات بالباركود - خيام ستور (Khiam Store)

نظام فحص وتجهيز ذكي لمخزن الملابس، يعمل كـ **Static Web App** مستقل، وكـ **Chrome Extension (Manifest V3)** للربط المباشر مع أوبريكس وبوسطة وشوبيفاي.

---

## ⚡ خطوات التشغيل السريع (خطوتان فقط)

### 1️⃣ الطريقة الأولى: التشغيل كرابط مباشر على GitHub Pages (أو المتصفح فوراً)
1. قم برفع ملفات المشروع إلى مستودع GitHub، ثم ادخل على:
   `Settings` -> `Pages` -> اختر فرع `main` واضغط **Save**.
2. سيمنحك GitHub رابطاً مباشراً مجانياً (مثال: `https://username.github.io/khiam-warehouse/`).
3. *(بدون إنترنت أو استضافة):* يمكنك أيضاً فتح ملف [`index.html`](index.html) مباشرة بالنقر المزدوج عليه في أي متصفح (Chrome أو Edge) وسيعمل النظام بكامل مميزاته محلياً.

---

### 2️⃣ الطريقة الثانية: التثبيت كـ Chrome Extension (Manifest V3)
1. افتح متصفح Google Chrome واذهب إلى الرابط:
   ```
   chrome://extensions/
   ```
2. في أعلى اليمين، قم بتفعيل **وضع مطور البرامج (Developer mode)**.
3. اضغط على زر **تحميل حزمة غير مضغوطة (Load unpacked)**، ثم اختر مجلد هذا المشروع:
   `f:\0\مراجعة المنتجات`
4. ستظهر إضافة **"خيام ستور | فحص الأوردرات بالباركود"** في شريط أدوات المتصفح، وبالضغط على أيقونتها ستفتح شاشة الفحص في تبويب كامل مستقل.

---

## 🌟 أبرز مميزات النظام المدمجة:
- **معالج الكيبورد العربي التلقائي 100%:** تصحيح مسح الباركود تلقائياً حتى لو كانت لغة جهاز الكمبيوتر مضبوطة على العربية.
- **الزر العائم على أوبريكس:** يظهر تلقائياً على صفحات التحضير في `khiiam.operix.co` لنقل الدفعات للشاشة بضغطة واحدة.
- **قراءة بوالص PDF واستخراج الملاحظات:** قراءة ملفات بوالص بوسطة PDF واستخراج الملاحظات الخاصة (مثل تعديل المقاس أو فحص الشحنة) وإظهارها كتنبيه بارز للعامل.
- **وضع استعلام عن منتج (Product Lookup Mode):** مسح أي قطعة في المخزن لمعرفة صورتها فوراً وأي الأوردرات في شيت اليوم بحاجة إليها.
- **مزامنة شوبيفاي الذكية:** سحب الصور من `khiam.store` وتخزينها محلياً للظهور في **0 مللي ثانية**.
- **صوتيات فورية (Web Audio API):** 4 نغمات احترافية وبدون أي تأخير للأوردرات الجديدة، المنتجات الصحيحة، اكتمال الأوردر، والتنبيهات الخاطئة.
